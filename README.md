# Debashis Moharana - Personal Portfolio

Personal portfolio website for Debashis Moharana, a Software Developer based in Pune, India. 

This site is built using **Astro**, a fast, static-site generator, utilizing the `astro-zen` minimalist theme and TailwindCSS.

## 🚀 Getting Started

To run the project locally:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```
   The site will be available at `http://localhost:4321`.

## 📦 Building and Publishing

To build the project for production, run:
```bash
npm run build
```

This will output the compiled static assets into the `dist/` directory.

### Cloudflare Pages Deployment

This site is configured to be deployed automatically to Cloudflare Pages.
You can also manually deploy it using the Wrangler CLI:
```bash
npx wrangler pages deploy
```

For more details on publishing, see [PUBLISH.md](./PUBLISH.md).
